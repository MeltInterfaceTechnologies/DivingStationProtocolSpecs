# DivingStationProtocol 仕様書

[English](README.md) | 日本語

DivingStationProtocol（DSProtocol）は、DivingStationを介してMelt Interface Technologies製デバイスと通信するためのOSC（Open Sound Control）プロトコルです。このリポジトリではプロトコルの仕様書を管理しています。

## 対応製品

| プロトコル | 対応製品 | 必要なDivingStationのバージョン |
| --- | --- | --- |
| [v1](docs/ds_protocol_v1.md) | ContactGlove、ContactGlove2、ContactSheet | v1.5.6以降 |
| [v2](docs/ds_protocol_v2.md) | ContactGlove3 Pro | v2.0.0以降 |

通常のContactGlove3ではDivingStationProtocolを使用できません。Protocol v2の対応製品はContactGlove3 Proのみで、v1の対応製品との互換性はありません。
