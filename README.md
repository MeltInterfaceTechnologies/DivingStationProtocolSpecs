# DivingStationProtocol specifications

English | [日本語](README_JA.md)

DivingStationProtocol (DSProtocol) is an OSC (Open Sound Control) protocol for communicating with Melt Interface Technologies devices through DivingStation. This repository contains the protocol specifications.

## Supported products

| Protocol | Supported products | Required DivingStation version |
| --- | --- | --- |
| [v1](docs/ds_protocol_v1_EN.md) | ContactGlove, ContactGlove2, ContactSheet | v1.5.6 or later |
| [v2](docs/ds_protocol_v2_EN.md) | ContactGlove3 Pro | v2.0.0 or later |

The standard ContactGlove3 cannot use DivingStationProtocol. Protocol v2 supports only ContactGlove3 Pro and is not compatible with the products listed for v1.
